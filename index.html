Aapka parivaar, sirf aapka

  • Har phone ka apna login. Invite link ek hi baar, 48 ghante chalta hai, aur admin ki haan ke bina koi nahi judta. Koi public profile nahi.
  • Koi ad nahi, koi tracking nahi, koi algorithm wali feed nahi.
  • Gupt note pe naam save hi nahi hota.
  • Photos chhoti karke app mein rehti hain. App khud gallery mein kuch save nahi karta.
  • Admin poore parivaar ki photos aur baatein ek ZIP file mein apne phone pe le sakta hai.

Agla kadam: end-to-end encryption, taaki photos aur baatein sirf parivaar ke phones pe khulein.

Sawaal

iPhone pe chalega?+

Haan. Safari mein kholo, Share → Add to Home Screen. Reminders bhi tabhi chalte hain (iOS 16.4 ya naya).

Play Store se download karna padega?+

Nahi. Link kholo aur Install dabao, app home screen pe aa jayega.

Paise lagte hain?+

Abhi free hai.

Phone ki jagah bharegi?+

Nahi. Photos chhoti karke app mein rehti hain. App khud gallery mein kuch save nahi karta.

Koi abhi juda nahi, toh?+

Uska naam pehle se jod do. Use invite link bhejo: woh apna naam chunega, aur admin haan karega.

Admin kaun hota hai?+

Jo parivaar banata hai, woh pehla admin. Admin naye phone ko haan karta hai, khoya phone hatata hai, aur kisi aur ko bhi admin bana sakta hai. Do admin rakhna achha hai.

Naya phone liya, ya phone kho gaya?+

Parivaar mein kisi se naya invite link maango aur apna naam chuno. Admin haan karega, aur khoya phone Parivaar tab se hata dega.

Photos ka backup?+

Admin Parivaar tab mein Backup download karo dabaye. Saari photos aur baatein ek ZIP file mein phone pe aa jaati hain.

Hindi script mein milega?+

Abhi Hinglish mein hai.
